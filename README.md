# Roji Studio

Site institucional da Roji Studio — sites e landing pages para negócios locais.

Construído com [Vite](https://vite.dev), React e [Motion](https://motion.dev) a partir do desenho em `assets/Roji-Site`.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Estrutura

- `src/components` — cada seção do site (Header, Hero, Idea, Features, Projects, HowItWorks, About, Contact, Footer)
- `public/images/projects` — capturas reais dos projetos (Hairv Club, Vista Clara, The Polittis, Park Patas), extraídas do desenho original
- `assets/` — material de referência original (PNGs e HTML editável do desenho)
